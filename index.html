Stored nowhere

The mechanical truths under the poetry

The estate is a pattern across its repositories, present wherever the current flows, stored in no one place. The precise mechanisms:

The topological field is a pure function over a content-signed snapshot (estate.json) — no shared mutable graph, no sync locks, and the frontier holds at most one active node. Placement is recomputed, never stored.
run(S) == S is a 64-bit FNV-1a content-addressed memoization (the estate's h16): the same spec collapses once, then replays. The 128-bit FNV content address is a separate hash — it names each memory record.
A bijective integer codec addresses fold-signatures; the 12 memory cells are addressed by LSH routing — two distinct mechanisms. Neither injects tensors into attention heads: the local engine's native prefix cache is respected, not hacked.
Nightly consolidation compresses transcripts into the LSH cells with zero weight updates — the corpus reorganises what it learned overnight; no model is retrained.
The ledger

Contribution recorded on a signed, conserved ledger

Useful work is accounted, not asserted. Every contribution the gate re-verifies is written to an internal ledger — the honest record of who did what.

Signed & hash-chained

Every entry is provable

Idle metal becomes a sovereign node that earns contribution by doing work the gate re-verifies. Each entry is signed and linked into a hash-chained ledger — tamper-evident, so the record of contribution can be checked, not trusted.

Conserved & closed

Internal accounting, no money out

The ledger is conserved — nothing is minted, every unit traces to verified work — and budget-bounded. It is closed internal accounting: contribution stays contribution, with no exchange or money-out path.
